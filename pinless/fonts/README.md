# Fuentes incluidas

- Barlow Condensed ExtraBold y Regular: titular, año y cifras.
- Manrope Medium: inscripciones, etiquetas y atribución.

Las familias usan SIL Open Font License 1.1. Las licencias y sus créditos completos
se incluyen junto a los archivos. No se necesitan las fuentes de Windows.

Fuentes originales: repositorio oficial de Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- https://github.com/google/fonts/tree/main/ofl/manrope

`Manrope-Medium.ttf` es una instancia estática de peso 500 de
`Manrope-variable.ttf`, creada con fontTools para que la salida no dependa del
soporte de ejes variables del renderizador.
